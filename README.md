# hxyfront-62007 植物标本馆入库 · 采集号分合台账

源提示词编号：9

植物标本馆压制标本入库前端。针对"几份标本共用一个采集号、改一份会覆盖整组资料"的问题，页面提供**采集号分合台账**：

- **按物种、采集地和日期核对合并**：采集号/物种不同 → 不可合并；采集地点或日期不同 → 停在待确认，逐条列出差异，人工确认后才成组；海拔/生境/采集人不同仅提示。
- **合并保留各自档号，指定主档展示详情**：合组只记录各份档号引用，不复制、不覆盖任何字段。
- **拆开恢复独立**：柜位与历史注记跟随原标本；已上柜记录只增不减，不因合并消失。
- **三层分离**：整理规则（`src/rules/`）、资料存取（`src/storage/`）、页面状态（`src/state/usePageState.ts`）分开维护。
- **数据留本机**：全部写入浏览器 localStorage，重开页面分合记录仍在；可导出 JSON / 重置演示数据 / 清空。

页面包含：入库队列（鉴定状态筛选 + 勾选合并）、合并核对工作台、待确认差异核对、合组台账与合组详情（拆出）、采集地点信息卡、单份标本详情（编辑只动本份、追加上柜/注记）、分合操作流水。

## 技术栈

React + Vite + TypeScript
